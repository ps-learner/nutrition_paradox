# Nutrition Paradox

A data engineering and visualization project exploring global nutrition trends using APIs, SQL, and Streamlit dashboards.

## Tech Stack
- Python
- Pandas
- SQLite
- SQLAlchemy
- Streamlit
- Plotly

## Folder Structure

```bash
nutrition_paradox/
```

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```
